# Paper Build Guide

This directory contains the IEEE-style LaTeX paper for the
**NS-3 O-RAN 6G Integration** project.

## Quick Start

```bash
# 1. Generate LaTeX assets (tables + figures) from simulation results
python3 ../tools/paper/generate_paper_assets.py

# 2. Build the PDF
cd paper
make          # needs latexmk + a LaTeX distribution (TeX Live / MiKTeX)
```

The compiled PDF appears as `paper/main.pdf`.

│   ├── algorithms.tex
│   ├── experimental_setup.tex
│   ├── results.tex            # Includes auto_results.tex
│   ├── auto_results.tex       # ← generated by generate_paper_assets.py
│   ├── discussion.tex
│   └── conclusion.tex
├── tables/
│   ├── sim_config.tex         # ← generated
│   ├── handover_kpi.tex       # ← generated
│   ├── mec_kpi.tex            # ← generated
│   └── ml_summary.tex         # ← generated

    ├── latency_cdf.tex        # ← generated

Files marked **← generated** are overwritten each time you run
`generate_paper_assets.py`.  The static section files (`introduction.tex`,
`related_work.tex`, etc.) and `architecture.tex` are **not** overwritten.

## Prerequisites

| Tool | Purpose |
|------|---------|
| Python ≥ 3.8 | Run `generate_paper_assets.py` |
| TeX Live ≥ 2020 (or MiKTeX) | Compile LaTeX |
| `latexmk` | Automated PDF build (usually bundled with TeX Live) |
| `pandas` *(optional)* | Faster CSV parsing in the generator |

Install a minimal TeX Live on Ubuntu/Debian:
```bash
sudo apt-get install texlive-base texlive-latex-extra texlive-science latexmk
```

## Workflow

### Step 1 – Run simulations
```bash
python3 oran_6g_demonstration.py   # or your preferred simulation script
```
Outputs land in `results/data/` as `.csv` and `.json` files.

### Step 2 – Generate paper assets
```bash
python3 tools/paper/generate_paper_assets.py
# or, from inside paper/:
make assets
```
This scans `results/` and writes populated `.tex` snippets into
`paper/tables/` and `paper/figures/`, and updates `paper/sections/auto_results.tex`.

### Step 3 – Edit narrative sections
Open the section files in `paper/sections/` and fill in the
narrative around the auto-generated numbers.
The auto-generated sections are marked with `% TODO` comments.

### Step 4 – Compile the PDF
```bash
cd paper && make
# or directly:
cd paper && latexmk -pdf main.tex
```

### Step 5 – Convenience build script
A shell script is also provided:
```bash
bash tools/paper/build_paper.sh
```
This runs both the asset generator and `latexmk` in one command.

## Makefile Targets

| Target | Action |
|--------|--------|
| `make` / `make pdf` | Compile `main.pdf` |
| `make assets` | Run the Python generator |
| `make all` | `assets` + `pdf` |
| `make clean` | Remove LaTeX auxiliary files |
| `make distclean` | Remove auxiliary files + PDF |

## Troubleshooting

- **Missing packages**: run `tlmgr install <pkg>` or install
  `texlive-latex-extra texlive-science`.
- **Generator finds no data**: ensure `results/data/` contains at least
  one `.csv` or `.json` file; the generator creates informative
  placeholder output otherwise.
- **Compilation error in auto-generated files**: re-run the generator;
  placeholder `.tex` stubs are always syntactically valid.
